# Monday.com Board Column Mapping

This document shows the mapping between your Monday.com board columns and the configuration used in the sync script.

_NOTE: This is for the Test board only_

## Board Columns

Based on your Monday.com board structure:

| Column Title       | Column ID            | Type      | Used In Sync | Purpose                                   |
| ------------------ | -------------------- | --------- | ------------ | ----------------------------------------- |
| Name               | `name`               | name      | ✅ Yes       | School name (item name)                   |
| Person             | `person`             | people    | ✅ Yes       | School owner                              |
| Main Contact       | `text_mkx76gqv`      | text      | ✅ Yes       | Contact full name (split into first/last) |
| Main Contact Email | `email_mkxew0yz`     | email     | ✅ Yes       | Contact email address                     |
| Item ID            | `text_mkx7bk6w`      | text      | ✅ Yes       | Used to track if synced to HubSpot        |
| School Website     | `text_mkx7zjs5`      | text      | ❌ No        | Not currently synced                      |
| Email address      | `text_mkx7at8`       | text      | ❌ No        | Duplicate of Main Contact Email           |
| Postcode           | `text_mkx74mph`      | text      | ❌ No        | Not currently synced                      |
| Phone Number       | `text_mkx76rq5`      | text      | ❌ No        | Not currently synced                      |
| Address            | `long_text_mkx7tazk` | long_text | ❌ No        | Not currently synced                      |
| Monday.com URL     | `text_mkx7ek05`      | text      | ❌ No        | Generated by script                       |
| Hubspot URL        | `text_mkx7by03`      | text      | ❌ No        | Not currently used                        |
| Subitems           | `subtasks_mkx7j35s`  | subtasks  | ❌ No        | Not used                                  |

## Configuration in `config.ts`

```typescript
export const COLUMN_IDS = {
    OWNER: 'person',
    MAIN_CONTACT: 'text_mkx76gqv',
    MAIN_CONTACT_EMAIL: 'email_mkxew0yz',
    HUBSPOT_RECORD_ID: 'text_mkx7bk6w',
};
```

## Data Flow Example

### Input (Monday.com)

```json
{
    "id": "18312635421",
    "name": "Test Primary School",
    "column_values": [
        {
            "id": "person",
            "text": "name"
        },
        {
            "id": "text_mkx76gqv",
            "text": "Tristram Shandy"
        },
        {
            "id": "email_mkxew0yz",
            "text": "tshandy@email.com"
        },
        {
            "id": "text_mkx7bk6w",
            "text": "" // Empty = not synced to HubSpot yet
        }
    ]
}
```

### Output (HubSpot-ready)

```json
{
    "schoolName": "Test Primary School",
    "owner": "Owner Name",
    "mainContact": {
        "firstName": "Tristram",
        "lastName": "Shandy",
        "email": "tshandy@email.com"
    },
    "mondayUrl": "https://learningwithparents.monday.com/boards/18311892303/pulses/18312635421",
    "mondayItemId": "18312635421",
    "createdAt": "2025-10-30T18:48:55Z"
}
```

## Filtering Logic

The script only processes schools where:

-   `text_mkx7bk6w` (Item ID) is **empty** or **null**

This ensures we only sync schools that haven't been synced to HubSpot yet.

## Future Enhancements

Additional columns that could be synced in the future:

-   School Website (`text_mkx7zjs5`)
-   Postcode (`text_mkx74mph`)
-   Phone Number (`text_mkx76rq5`)
-   Address (`long_text_mkx7tazk`)

To add these, simply:

1. Add the column ID to `COLUMN_IDS` in `config.ts`
2. Update the `TransformedSchoolData` interface in `types.ts`
3. Extract the value in `transformSchoolsForHubSpot()` in `transform.ts`
