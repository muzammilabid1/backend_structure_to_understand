## Schema dump

This folder stores the canonical PostgreSQL schema-only dump generated automatically from the current migrations.

There is a single schema file that always reflects the database structure produced by running all migrations from scratch.

### Structure

-   `graphql-provider/schema-dump/latest-schema.sql` — canonical schema file

### File naming

The schema file is always:

`latest-schema.sql`

### How the file is created

The workflow:

1. Triggers when a Pull Request contains migration changes.
2. Runs all migrations on a fresh database.
3. Generates a schema-only dump.

### Notes

-   Schema-only (no data).
-   Generated by CI — do not edit manually.
-   All database changes must go through migrations.
